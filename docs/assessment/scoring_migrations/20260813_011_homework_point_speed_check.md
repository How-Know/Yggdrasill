## 변경 목적

v2 과제 완료 포인트는 오래 붙잡고 검사를 많이 받을수록 가산했다. 실제 품질은
권장시간 안에 끝내는 것과 한 번에 통과하는 쪽이다. 기본 10P와 보너스 상한
(시간 6 / 검사 4)은 유지해 지급 구간 `10~20`과 부스터 후 `6~40`을 깨지 않는다.

## 변경 전

```
base = 10 + min(누적분/90, 1) × 6 + min(검사횟수/5, 1) × 4
```

오래 할수록, 검사 많을수록 많았다. `rule_version = point_rule_v2`.

## 변경 후

```
base = 10 + time_bonus + check_bonus
지급 = max(round(base × booster), 1)
```

`rule_version = point_rule_v3`. 부스터 산식은 그대로다.

### 시간 보너스 (최대 6P)

| 조건 | 보너스 |
| --- | --- |
| 레거시 (문항 스냅샷 없음) | 0 (고정 10 + 검사 보너스만) |
| 권장시간 없음 | 0 |
| 생성 후 5분 이내 완료 | 0 (비정상 속전) |
| 실측 시간 0 | 0 |
| 권장시간 이상 소요 | 0 |
| 권장시간 안쪽 완료 | `(1 - 실측분/권장분) × 6` |

권장시간은 `coalesce(recommended_minutes, recommended_minutes_auto)`.
마이그레이션 여부는 `homework_item_problems` 존재로 판별한다.

### 검사 보너스 (최대 4P)

1회 만에 통과가 최고점. 4회부터는 없다.

| 검사 횟수 | 보너스 |
| --- | --- |
| 0 또는 1 | 4.00 |
| 2 | 2.67 (`4 × 2/3`) |
| 3 | 1.33 (`4 × 1/3`) |
| 4 이상 | 0 |

0회는 검사 없이 완료된 경우(교사 직접 완료 등)로, 추가 재검사를 받지 않은 것과
같게 본다.

## 영향 범위

- 서비스 계산식: `_grant_homework_completion_points`만. 출석 포인트·부스터·과제 점수 v2는 불변.
- UI: 지급액 표시만 바뀐다. 공식 문구를 앱에 하드코딩하지 않음.
- 데이터: 이미 지급된 원장은 소급하지 않음. 이후 완료분부터 `point_rule_v3`.
