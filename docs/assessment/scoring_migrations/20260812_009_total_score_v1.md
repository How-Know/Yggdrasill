## 변경 목적

지금까지 출석 점수와 과제 점수를 각각 따로만 보여줬다. 학생이 "나는 지금 전체적으로
어느 정도인가"를 한 숫자로 확인할 수 있게 총점을 도입한다.

학생앱 내정보 상단에는 이미 총점 카드 자리가 있었지만 출석 점수만 그대로 넣고 있었다.
이제 실제 가중 평균을 넣는다.

## 변경 전

- `scoring.md` 7)의 「총점/자동 반영 파이프라인: 아직 미도입(2단계 이후)」
- 학생앱 `profile_screen.dart`: `totalScore = score?.score100` (출석 점수 그대로)
- 학습앱 스탯 탭: 총점 표시 없음

## 변경 후

### 공식

```
총점 = (0.4 × 출석점수 + 0.6 × 과제점수) / (0.4 + 0.6)
```

분모를 명시적으로 나눠 둔 이유는, 다음 지표가 추가될 때 같은 재정규화 규칙으로
합류시키기 위함이다.

### 파라미터

| 이름 | 값 | 위치 |
| --- | --- | --- |
| 출석 가중치 | 0.4 | `DataManager.totalWeightAttendance` / `v_w_att` |
| 과제 가중치 | 0.6 | `DataManager.totalWeightHomework` / `v_w_hw` |
| formula_version | `total_score_v1` | 양쪽 |

과제 비중을 더 크게 둔 이유는 과제가 핵심 학습 행위이고 출석은 전제조건 성격이기
때문이다.

### 근거 부족 처리 (표시 숨김)

총점은 **출석 근거와 과제 근거가 모두 있을 때만** 계산한다.

- 출석 근거: 가중 출석 이벤트 합 `total_weight > 0`
- 과제 근거: 과제 이벤트 수 `event_count > 0`

근거가 없으면 점수를 `null`로 두고 숫자를 숨긴 뒤 안내 문구를 보여준다.

| 상황 | 안내 문구 |
| --- | --- |
| 과제 기록 없음 | `과제를 처리하면 총점이 생겨요` |
| 출석 기록 없음 | `출석 기록이 쌓이면 총점이 생겨요` |

과제를 0점으로 섞어 평균을 내면 신입 학생의 총점이 부당하게 낮게 시작하므로
그 방식은 채택하지 않았다.

### 순위

총점을 낼 수 있는 학생(양쪽 근거 보유)만 모아 순위를 낸다. 총점이 없는 학생은
모집단에서 제외되므로 상위 %가 왜곡되지 않는다.

## 구조상 주의점 (중요)

과제 점수가 이제 **두 곳**에 존재한다.

- 학습앱: `apps/yggdrasill/lib/services/homework_score_service.dart` (Dart)
- 서버: `public._homework_score_all_v1` (SQL)

출석 점수도 이미 같은 구조였다(`AttendanceService.calculateAttendanceScore` ↔
`_attendance_score_all_v1`). 학생앱은 Dart 계산 결과에 접근할 수 없으므로 서버 미러가
필요하다.

**한쪽 공식을 바꾸면 반드시 양쪽을 같이 바꿔야 한다.** 파라미터는 다음과 같이 일치해야
한다.

| 항목 | 값 |
| --- | --- |
| 과제 반감기 | 180일 |
| 과제 scaleK | 240 |
| 배정 base XP | 0.45 (+진행률 0.20, +완료힌트 0.15) |
| 검사 base XP | 0.95 (+진행률 0.35) |
| 완료 base XP | 3.80 (+시간 최대 1.50, +검사 최대 1.00) |
| 출석 반감기 | 28일 |
| 출석 유효표본 | 8.0 |

### 부수 리팩터링

기존 `student_get_attendance_score_v1`의 계산 로직을 `_attendance_score_all_v1`
헬퍼로 추출하고, RPC는 헬퍼를 조회하는 얇은 래퍼로 바꿨다. 출력 컬럼과 반올림은
동일하다. 총점 순위를 내려면 학원 전체 학생의 출석 점수가 필요했고, 로직을 복사하면
두 벌이 드리프트하기 때문이다.

## 영향 범위

- 서비스: `DataManager.calculateTotalScoreWithRankAsync` 신규.
  출석은 학생별 동기 계산, 과제는 코호트 배치 1회 조회로 묶었다.
- DB: 헬퍼 함수 2개 신규, `student_get_attendance_score_v1` 재작성(출력 동일),
  `student_get_total_score_v1` 신규.
- UI(학습앱): 스탯 탭 최상단에 `총점` 섹션 추가. 출석 기록 변경에도 반응하도록
  `attendanceRecordsNotifier` 리스너를 연결했다.
- UI(학생앱): 내정보 상단 좌측 총점 카드가 실제 총점을 표시. 근거 부족 시 `—` + 안내.
- 데이터 저장: 없음(실시간 계산). 스냅샷은 `scoring_snapshot_policy.md` 정책을 따른다.
