# 과제 권장시간·페이스 관리 로드맵

2026-07 과제 마감/권장시간 설계 논의 정리. 구현 완료된 것과 앞으로 할 일을 구분해 둔다.

## 핵심 결정 사항 (설계 원칙)

- **권장시간은 마감이 아니라 페이스 지표다.** 과제의 완료 조건은 항상 범위(문항)이며,
  권장시간은 "이 분량이면 이 정도 시간"을 보여주는 용도. 시간을 채웠다고 완료되지 않고,
  시간을 넘겼다고 실패도 아니다. (대충 풀어서 마감 맞추는 행동을 유도하지 않기 위함)
- **회차(밀린 과제)는 `homework_assignments` 가 담당한다.** 과제 항목(homework_items)은
  내용(범위) 고정, 배정(assignments)은 회차마다 새 행. `carry_over_from_id` 로 이월 추적.
- **정산 경계는 하원(퇴실) 이벤트.** 학생 자율 체크는 신뢰하지 않는다. 하원 시점에
  해당 세션의 진행 상태를 잠정 정산한다.
- **통계에 넣는 실측은 "간이 시험(학생용 테스트)" 데이터만.** 평상시 학원 감시 기록
  (딴짓/졸음 등)은 아직 보조 기록일 뿐 권장시간 보정에 쓰지 않는다. 기록은 문항 단위.
- **권장시간 = 순수 문제 풀이시간 + α.** α 는 전환/검사/이동 등 오버헤드.
  나중에 실측이 쌓이면 학생별로 `(실제 과제 완료시간 − 순수 풀이시간)` 평균으로 α 를
  역산하고, 과제별 권장시간을 `순수시간 + α` 로 재계산한다.
- **자동 제안값과 사람 확정값을 둘 다 저장한다.**
  `recommended_minutes_auto`(계산값) vs `recommended_minutes`(확정값).
  차이가 곧 "사람의 교정"이라 기본 단가를 보정할 학습 데이터가 된다.
- **미완료 사유(속도/난이도/태도)는 검사자가 입력하지 않는다.** 주관적이므로,
  시간·정오 데이터에서 나중에 통계적으로 유도한다.

## 구현 완료 (2026-07-29 기준)

- 학생-교재 바인딩 해제 RPC + UI (`unbind_student_textbook`,
  `20260727170000_unbind_student_textbook.sql`). 학생 스코프 데이터만 삭제, 원본 교재 보존.
- **권장시간 1단계 (초기값 기반 제안)**:
  - `homework_time_defaults` 테이블 — (시리즈, 과정, 카테고리)별 문항당 초 단가.
    전역 키: `item`(분류 없는 문항), `page`(페이지), `item_overhead`(문항 전환),
    `task_overhead`(하위과제당). (`20260729010000_homework_recommended_time.sql`)
  - `homework_items.recommended_minutes` / `recommended_minutes_auto` 컬럼.
  - `HomeworkTimeDefaultsService` — 단가 로드/캐시, 시리즈별 카테고리 키
    (개념+유형: 6개 코너, 쎈·RPM: A/B/C/실력 UP,
    개념원리: section 기반 5종 + 연습문제 실력 UP),
    권장시간(분) 계산.
  - 경험 기반 초기 단가 시드:
    - 초기 α는 과제 그룹당 10분(준비·이동·채점·검사). 저장 스냅샷은
      하위과제별로 α를 포함하지만 그룹 합계에서는 중복분을 빼고 한 번만 계산.
      실측이 쌓이면 학생별 값으로 교체.
    - 개념+유형 중등: 개념확인 30초, 나머지 2분.
    - 개념원리 고등: 개념원리 익히기 1분, 연습문제 실력 UP 5분, 나머지 2분.
    - 쎈 중등 A/B/C 20초/1분 30초/5분, 고등 30초/2분/6분.
    - RPM 중등 A/B/C/실력 UP 20초/1분 30초/1분 30초/5분,
      고등 30초/2분/2분/6분.
    - 추출 문서에 단가를 복제하지 않고 출제 시 시리즈·과정·문항 분류로 조회하므로
      같은 시리즈의 이후 추출분에도 자동 적용. 신규 시리즈는 단가 행을 별도 추가.
  - 과제 추가 다이얼로그 — 하위과제 초안별 자동 계산 표시(`권장 N분`),
    편집 다이얼로그에서 수동 수정(자동 제안값은 hint 로 유지), 초안 리스트 상단에 합계 표시.
  - 저장 배선 — 그룹 생성/단일 생성 경로 모두 DB 저장. 서버 컬럼 미적용 시
    자동 폴백(기능만 조용히 꺼짐).

## 앞으로 구현할 것

### Phase 1.5 — 초기값 입력·운영 편의 (즉시)

- [x] 관리자 경험 기반 초기 단가 시드 마이그레이션.
- [ ] 단가 편집 UI (설정 화면). 지금은 SQL 로 직접 수정.
- [ ] 하원 정산 다이얼로그(departure draft)에 그룹별/전체 권장시간 합계 표시.
- [x] 관리자 홈 과제카드에 권장시간 표시. 상단 플로우칩 자리에 표시하고,
  펼친 그룹 카드에서는 하위 과제 수 옆에 플로우칩 표시.
- [ ] 학생 앱 과제카드에 권장시간 표시 (제한시간과 구분되는 톤으로).
- [ ] 예약 과제 RPC(`homework_create_reserved_homework_bundle`) 재도입 시
  `recommended_minutes(_auto)` 패스스루 추가. (현재 RPC 는 20260722230000 에서 drop 됨)

### Phase 2 — 간이 시험(학생용 테스트) 실측 수집

- [ ] 문항 단위 시간·정오 기록 스키마 확정 (learning_attempts 확장 또는 신규 테이블).
  포함 필드: 문항 좌표(book_id/grade_label/crop or pb_question_uid, 유형 카테고리),
  소요시간(ms), 정오, 측정 환경(간이 시험 = 신뢰 표본 플래그).
- [ ] 학생 컨텍스트 스냅샷 — 시도 시점의 학년, 수준(레벨), 목표 등급을 함께 저장.
  (나중에 백분위 모수 선택이 가능해지는 근거 데이터)
- [ ] 간이 시험 출제/응시/채점 플로우.

### Phase 3 — 권장시간 자동 보정

- [ ] 순수 풀이시간 통계: 간이 시험 실측으로 (시리즈, 카테고리)별 단가 갱신
  (초기값 → 실측 가중 평균으로 점진 전환).
- [ ] 학생별 α 역산: `실제 과제 완료시간 − Σ(순수 풀이시간)` 의 이동 평균.
  과제별 권장시간 = 순수시간 합 + 학생 α.
- [ ] 사람 교정 반영: `recommended_minutes` vs `recommended_minutes_auto` 차이 통계로
  단가 바이어스 감지 (특정 유형을 늘 20% 늘려 잡는다면 단가를 수정).

### Phase 4 — 수준·목표 기반 개인화

- [ ] 학생 수준(레벨) 및 희망 등급(목표) 데이터 확정 (조사 예정).
- [ ] 권장시간을 목표 등급 기준으로 산출, 결과지는 현재 수준 기준과 비교 표시.

### Phase 5 — 백분위(상위 %) 표시

- [ ] 원자적 사실 저장 확립(Phase 2 스키마가 전제): 학생 맥락 + 문항 좌표 + 시간 + 정오.
- [ ] 모수(비교군) 선택 뷰: 동학년 기준 / 다음 학년 기준 / 동일 수준 기준 등
  관점을 바꿔가며 백분위 확인.
- [ ] 시간 정규화: 실력이 늘면 문항당 시간이 하한에 수렴한다는 가정 → "하한 대비 배수"
  지표 검토. 표본 희소 구간은 목표 등급 기준선으로 대체 표시.

## 초기값 입력 방법 (참고)

단가는 `homework_time_defaults` 에 초 단위로 저장. 예시:

```sql
insert into public.homework_time_defaults (
  academy_id, series_key, school_level_key, category_key, seconds_per_unit
)
values
  (:academy, 'ssen', 'middle', 'A',  20),
  (:academy, 'ssen', 'middle', 'B',  90),
  (:academy, 'ssen', 'middle', 'C', 300),
  (:academy, 'ssen', 'high',   'A',  30),
  (:academy, 'ssen', 'high',   'B', 120),
  (:academy, 'ssen', 'high',   'C', 360)
on conflict (academy_id, series_key, school_level_key, category_key)
  do update set seconds_per_unit = excluded.seconds_per_unit, updated_at = now();
```

폴백 순서: `(시리즈, 과정, 카테고리)` → `(시리즈, 공통, 카테고리)` →
`(전역, 과정, 카테고리)` → `(전역, 공통, 카테고리)` → 같은 순서의 `item`.
단가가 하나도 없으면 권장시간 기능은 표시되지 않는다 (조용히 꺼짐).
