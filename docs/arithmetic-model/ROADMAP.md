# 남은 일

## 이번 버전에 들어 있는 것

- 자연수 37유형을 기존 코드에 연결한 최초 기준 시간 시드
- 초안 25개. 끄면 기존 분류를 유지하고, 켜도 메모리 판정만 바뀐다
- 자연수 사칙의 속성 추출과 분류
- 속도·정확도·숙련도, 분위수, 수축 보정, 자동 적용 판정
- 문항 비용 설명(이미 가중된 사고 점수, 50점 앵커)
- 개념 탭 연산 시트의 모델 칸과 시뮬레이터 6개
- 정책 버전 발행

## 일부러 아직 없는 것

- 학생 측정 화면과 시도 저장. 학원 앱, 학생 앱, 키오스크 중 어디인지 정한 뒤에 탈퇴 삭제 목록과 함께 넣는다.
- 보정 결과를 `arithmetic_reference_revisions`에 쓰는 일. 측정이 생기기 전에는 가상 계산만 한다.
- 제안 비용을 승인해서 `unit_score`를 바꾸는 일. 기존 연산 사전의 점수 칸이 아직 그 역할이다.
- 개인 곡선 적합, 속성 회귀, 학원 사이 통계.
- 분수·소수·식의 속성 추출. 자연수 이항만 읽는다. 혼합 연산은 거절한다.
- 두 자리 곱셈의 "받아올림이 적음"은 부분곱 올림과 합산 올림의 합이 1 이하라는 임시 규칙이다.
