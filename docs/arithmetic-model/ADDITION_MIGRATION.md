# 자연수 덧셈 이관

자연수 덧셈만 식 하나의 모델로 계산한다. 뺄셈, 곱셈, 나눗셈과 그 위 유형은 기존 유형별 비용이다.

## 화면

개념 탭 → 연산 손잡이 → 자연수 덧셈 → **자연수 덧셈 모델**.

예전 10개 줄의 ± 점수는 이 목록에서 빼 두었다. 그 점수는 DB `arithmetic_primitives.unit_score`에 그대로 있고, 모델 안의 프리셋에 이전 비교값으로 보인다. 문항이 식 없이 횟수만 가진 경우에는 그 이전 비용이 계속 쓰인다. 저장된 문항 난이도는 다시 계산하지 않는다.

## 대표식

| 2+3 | 0.10 | 0.100 | 1.0초 | 1.000초 |
| 7+8 | 0.15 | 0.165 | 1.3초 | 1.730초 |
| 23+4 | 0.15 | 0.139 | 1.8초 | 1.480초 |
| 27+8 | 0.22 | 0.200 | 2.3초 | 1.990초 |
| 98+7 | 0.28 | 0.270 | 3.0초 | 2.670초 |
| 23+45 | 0.20 | 0.178 | 2.5초 | 1.870초 |

| 78+57 | 0.40 | 0.319 | 3.5초 | 3.160초 |
| 234+53 | 0.42 | 0.215 | 4.5초 | 2.330초 |
| 687+586 | 0.55 | 0.465 | 6.0초 | 4.530초 |

이전 기준은 지난 유형별 시드다. 모델 값은 `378+245`가 0.383점, 3.710초가 되도록 맞춘 시드 v1이다.

## 되돌리기

`arithmetic_addition_legacy`가 이관 직전의 `unit_score`, `est_seconds`를 담는다. 그 표는 기존 행을 덮어쓰지 않는다. 앱에서 계수를 시드 v1으로 되돌리면 화면 계산만 돌아간다.
