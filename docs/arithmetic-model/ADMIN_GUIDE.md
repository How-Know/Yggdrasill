# 관리자 안내

1. 개념 탭에서 오른쪽 **연산** 손잡이를 연다.
2. 머리 탭에서 **모델**을 고른다. 세부 연산 목록과 비용 편집은 그 옆 탭에 그대로 있다.
3. **개요**의 식 칸에 `13-8`처럼 넣으면 분류 코드와 초안 후보가 보인다. 초안은 저장된 문항을 다시 분류하지 않는다.
4. **시뮬레이터** 여섯 칸은 가상 숫자다. 칸을 고쳐도 운영 정책과 연산 비용은 바뀌지 않는다.
   - 학생 점수: 기준 1.0초, 실제 1.5초, 정확도 95 → 속도 66.7, 숙련도 63.3
   - 기준 시간: T0 1000, Td 800, k 20, 학생 30 → 후보 880ms, 12%라 승인 필요
   - 문항 비용: 운영 기본은 연산 10 + 이미 가중된 사고 40 = 50. 5를 곱하는 보기는 가설이다
   - 속성 시간: `297+8` → 2.49초
   - 학습 곡선: 8초에서 1초로 가는 가상 곡선
   - 비용과 시간: 메모 허용 프로토콜의 시드만 점으로 그린다
5. **설정**에서 숙련 정확도, 숙련 속도, k, 앵커를 고치고 사유를 적은 뒤 **새 버전으로 발행**한다. 발행 전에는 운영 값이 아니다. 다른 사람이 먼저 저장했으면 거절하고 다시 읽는다.
6. **설명**은 왜 그 숫자인지를 적는다. **이력**은 발행 기록이다.
7. 왼쪽 메뉴의 연산 화면도 같은 모델 탭을 가지고 있다. 쓰는 곳은 개념 탭 시트다.

마이그레이션을 적용하기 전에는 계산은 되고, 운영 정책 읽기와 발행은 실패 안내를 보여 준다.

학생 측정, 주간 자동 보정 실행, 비용 승인으로 `unit_score`를 바꾸는 버튼은 없다.
