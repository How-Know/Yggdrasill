# 자연수 덧셈 모델

모델 id는 `natural.addition`이다. 식 `a+b`만 받는다. 자릿수와 받아올림 유형으로 점수를 고르지 않고, 열별 속성으로 비용과 시간을 계산한다.

비용과 시간은 같은 속성에 다른 계수를 곱한다. 비용 1점은 1000으로 저장한다. 시간은 밀리초다.

시드 v1의 출발은 2+3 = 0.100점, 1.000초다. 하한은 0.025점, 350ms다. 계수는 `packages/ygg_arithmetic/lib/src/natural_addition/addition_engine.dart`의 `AdditionSeed.v1`이 단일 출처다.

378+245는 유효 열 3, 받아올림 2, 연쇄 1이다. 비용 0.383점, 시간 3.710초.

0과 더하면 한쪽 숫자 열의 비용은 빼고, 항등 할인을 적용한다. 읽기와 답 자릿수 시간은 남긴다.

네 자리 이상은 외삽이다. 측정 프로토콜은 가로식, 암산, 숫자 입력 후 확인이다. 메모를 허용하는 시간과 섞지 않는다.

다른 연산을 같은 구조로 넣을 때는 추출기와 시드만 추가하면 된다. 이번 코드는 덧셈만 등록한다.
