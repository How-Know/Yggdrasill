# 결정 스펙

매니저앱 Think에서 **확정한 결정**을 구현용 문서로 내보낸 곳이다.
Cursor 같은 코딩 에이전트가 구현할 때 이 문서를 근거로 삼는다.

## 만드는 법

1. 매니저앱 → Think → 기억 탭 → 확정된 결정을 고른다.
2. "스펙 내보내기"를 누르면 AI가 결정을 아래 형식으로 옮긴다. 결정에 없는 내용은 "열린 질문"으로 빠진다.
3. 내용을 확인·수정한 뒤 "파일로 저장"한다. 기본 위치가 이 폴더다.
   저장한 경로는 그 결정의 `spec_path`에 기록된다.

파일 이름: `YYYYMMDD-제목.md` (결정일 기준)

## 형식

```
# {결정 제목}
- 상태 / 결정일 / 기억 id
## 배경
## 결정
## 이유
## 검토한 대안
## 구현 범위 (해야 할 것 / 하지 않을 것)
## 영향 받는 부분
## 지켜야 할 철학·원칙
## 완료 조건
## 열린 질문
```

## 규칙

- 스펙은 결정의 사본이다. 원본은 DB(`ai_memories`)다. 결정을 바꿨으면 스펙을 다시 내보낸다.
- 구현하다가 결정과 다르게 가야 하면, 코드를 먼저 바꾸지 말고 Think에서 결정을 고친 뒤 다시 내보낸다.
- "열린 질문"이 남은 스펙은 구현 전에 사람에게 먼저 묻는다.
